# 视频急救工具

行车记录仪、监控录像的视频文件打不开?一键修复转成 MP4。

- 支持 TS / MP4 / 大华 DAV,以及 00001.ts 分段录像自动合并
- 原文件绝不改动,修复结果另存新文件
- 修不好的老实说明并引导官方渠道,绝不硬凑坏文件
- 纯本地运行,不联网、不收集任何数据

## 下载

到 [Releases](https://github.com/zxy-666666Max/video-rescue/releases) 下载 VideoRescue_v1.0.zip,
解压后双击 VideoRescue.exe。详细步骤见压缩包内 使用说明.txt。

## 说明

- 内置 ffmpeg 7.1.1 静态版(来自 gyan.dev 的 GPL 构建,FFmpeg 源码:https://github.com/FFmpeg/FFmpeg)
- 使用 Python 3.11 + tkinter 编写
